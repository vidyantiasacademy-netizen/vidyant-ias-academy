# Languages (English, Hindi)

English is the default. Hindi is served under `/hi`.

| URL | Renders |
| --- | --- |
| `/courses` | English (internally `/en/courses`) |
| `/hi/courses` | Hindi |
| `/en/courses` | redirects to `/courses` |

## How it works

- **Routes** live under `src/app/[lang]/`. The root layout is
  `src/app/[lang]/layout.tsx`, so `<html lang>` matches the page. The Sanity
  Studio (`src/app/studio`) and `/api` sit outside `[lang]` and are never
  localised.
- **`src/proxy.ts`** rewrites a bare path to `/en/...`, collapses `/en/...` to the
  bare path, and remembers the reader's choice in the `NEXT_LOCALE` cookie. A
  bare path from a reader whose cookie says Hindi is redirected to `/hi/...`, so
  hard-coded links and server `redirect()`s keep them in Hindi. Crawlers carry
  no cookie, so the bare URLs they index are English.
- **Locale list** — `src/i18n/config.ts`. Adding a language is: add it to
  `LOCALES` and `LOCALE_META`, add `src/i18n/dictionaries/<id>.ts`, register it
  in `dictionaries/index.ts`. The Studio picks it up from the same list.

## In code

| Need | Use |
| --- | --- |
| Locale in a Server Component / `generateMetadata` | `await getLocale()` from `@/i18n/server` |
| UI strings on the server | `await getDictionary()` from `@/i18n/server` |
| Locale / strings in a Client Component | `useI18n()` / `useLocale()` from `@/i18n/I18nProvider` |
| A link | `import Link from "@/i18n/Link"` — prefixes `/hi` for Hindi readers |
| Active-link checks | `usePathnameWithoutLocale()` — `/hi/courses` → `/courses` |
| Page metadata | `export const generateMetadata = () => pageMetadata({...})` — canonical and `hreflang` per locale |
| `revalidatePath` | `revalidateLocalizedPath("/admin/courses")` from `@/i18n/revalidate` |
| Sanity content | pass the locale: `getFaqs(await getLocale())` |

`getLocale()` uses `next/root-params`, which does not work in Client
Components, Server Actions or Route Handlers.

Dictionaries are TypeScript, not JSON: `hi.ts` is typed against `en.ts`, so a
key missing in Hindi fails `npm run typecheck`. Placeholders use `{name}` and
`format()` from `@/i18n/dictionaries`.

## What is translated today

The site chrome — header, mobile menu, footer, sticky CTAs, 404 — and the
language switcher. Page bodies still render their English copy on `/hi` until
their strings move into the dictionaries. Editorial content is translated in
Sanity; see `docs/sanity.md` → Translations.
